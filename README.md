# God of War Legacy

## Sobre o Projeto

God of War Hub é uma plataforma web inspirada na franquia God of War, desenvolvida como Projeto Integrador. O sistema reúne informações sobre os principais jogos da saga e oferece funcionalidades interativas que permitem aos usuários testar seus conhecimentos, evoluir seu personagem e acompanhar seu desempenho.

## Funcionalidades

- Página inicial com informações sobre os jogos da franquia.
- Sistema de cadastro e login.
- Quizzes temáticos sobre a saga.
- Sistema de XP baseado nos acertos dos quizzes.
- Compra e gerenciamento de equipamentos.
- Evolução dos atributos de Kratos (Força, Velocidade, Defesa e Vitalidade).
- Dashboard com gráficos e indicadores de desempenho.

## Banco de Dados

O banco de dados foi modelado para gerenciar usuários, experiência, equipamentos e desempenho nos quizzes.

### Principais Entidades

usuario: dados dos usuários cadastrados.
avatar: atributos do personagem Kratos.
equipamento: itens disponíveis para compra e equipagem.
arsenal: equipamentos adquiridos pelo usuário.
equipamento_selecionado: itens atualmente equipados.
experiencia: histórico de XP obtido.
acertosQuiz: desempenho dos usuários nos quizzes.
requisito_equipamento: pré-requisitos para desbloqueio de equipamentos.

## ODS Relacionada

O projeto está alinhado à ODS 4 – Educação de Qualidade, utilizando conteúdos informativos e quizzes para incentivar a aprendizagem sobre a franquia e seus elementos mitológicos.
